# Social Media Engagement Analytics

## About the Project

This project analyzes social media engagement data using Python to identify patterns in content performance, user behavior, device usage, and sentiment.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Key Analysis

- Data cleaning and preprocessing
- Exploratory data analysis
- Engagement analysis
- Statistical analysis
- Data visualization
- Sentiment analysis
- User and device behavior analysis

## Key Findings

- Video posts had the highest average engagement score.
- Music was the highest-performing content category.
- Brazil had the highest average engagement rate.
- The 46–60 age group had the highest average engagement rate.
- Verified accounts had a higher average engagement rate.
- Mobile users had the highest average watch time.
- Negative posts had the highest average engagement rate.

The project demonstrates how Python-based data analysis and visualization can be used to understand social media engagement patterns and generate meaningful insights.
